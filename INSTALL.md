# Pixstory Admin Panel - Installation Guide

Follow these steps to set up and install the Pixstory Admin Panel on your server or local environment.

## Requirements
- PHP >= 8.1
- MySQL >= 5.7 or MariaDB >= 10.3
- OpenSSL PHP Extension
- PDO PHP Extension
- Mbstring PHP Extension
- Tokenizer PHP Extension
- XML PHP Extension
- Ctype PHP Extension
- JSON PHP Extension
- BCMath PHP Extension
- Composer

---

## 1. Installation Steps

### Step 1: Extract the Package
Extract the admin panel source code zip file into your web server's public directory.

### Step 2: Install Dependencies
Open your terminal, navigate to the root directory of the project, and install the PHP dependencies using Composer:
```bash
composer install --no-dev --optimize-autoloader
```
*(Do not ship the `vendor/` folder when packaging; it will be automatically generated by the command above).*

### Step 3: Configure Environment Variables
Copy the `.env.example` file to create your `.env` configuration file:
```bash
cp .env.example .env
```
Open the `.env` file and configure your database connection and application URL:
```env
APP_NAME=Pixstory
APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com/

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=your_database_name
DB_USERNAME=your_database_user
DB_PASSWORD=your_database_password
```

### Step 4: Generate Application Key
Generate the Laravel encryption key:
```bash
php artisan key:generate
```

### Step 5: Run Migrations and Seed Database
Run the database migrations and seed the default configuration settings, permissions, and the default admin user:
```bash
php artisan migrate --seed
```
This single command constructs all the required tables and inserts default system configuration rows.

---

## 2. Default Credentials
Once seeded, you can log in to the admin panel with:
- **URL:** `https://yourdomain.com/admin/dashboard` (or `http://localhost/admin/dashboard`)
- **Email:** `super@admin.com`
- **Password:** `password`

> [!IMPORTANT]
> Immediately upon logging in, navigate to the **Profile** or **Settings** section to change the default admin email and password.

---

## 3. Configuration & Security

### API Security Key
During the seeding process, a strong, random 32-character API key is automatically generated and saved in your `settings` table (under `api_authorization`).
- To find your key, you can view the `settings` table in your database or locate it under the admin settings panel.
- Ensure your Android Client uses the **same** API key for authorization headers to register devices.

### Push Notifications (OneSignal)
Navigate to the Admin Panel Settings and configure your:
1. `OneSignal App ID`
2. `OneSignal REST API Key`
